# Wanderlust – Airbnb Style

A full-stack Airbnb-style property listing web application where users can explore, search, create, edit, and delete listings and reviews.

##  Features

* JWT-based authentication with HTTP-only cookies
* Property listing CRUD operations
* Review CRUD operations
* Search and filtering
* Image uploads with Cloudinary
* Interactive maps with Leaflet
* Toast notifications
* Protected routes and authorization

##  Tech Stack

**Frontend:** React.js, Vite, React Router, Axios, Bootstrap

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT

**Other:** Cloudinary, Leaflet, Git, GitHub, Postman
